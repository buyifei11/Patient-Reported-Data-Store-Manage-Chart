Fields:
- symptom: nausea or vomiting, only when the source explicitly describes that symptom.
- assertion: present for an actual symptom, absent for an explicit denial, hypothetical for a feared or conditional event, uncertain for uncertainty about whether it occurred. Uncertainty about the count does not make an explicitly occurring symptom uncertain. Never turn an unmentioned symptom into an absent one.
- count: the stated number of vomiting episodes, including zero for explicit absence; otherwise null. Vague quantities are null. Do not infer one merely because vomiting is mentioned. Do not calculate a total from multiple statements. Nausea count is always null.
- count_scope: event for an individual episode, window for a described interval such as a meal or morning, day_to_date for today's cumulative count so far, day_total only for an explicitly complete total for a completed day. An evening report saying today's total is still day_to_date. Use null if the source does not establish scope; nausea scope is null. A single episode within a meal interval can have count 1 and scope window. Explicit absence today has count 0 and scope day_to_date. Preserve a stated scope even if the count is vague.

- severity_context: worst_today_so_far only for an explicit worst-so-far-today rating; current for an explicitly current rating; other for an explicit different context; unknown if a rating has no stated context; null if there is no rating.
- time_text: the original phrase that establishes the candidate's timing, or null when none is stated. Keep the source wording.

- clock_time: an exact stated clock time in HH:MM form, otherwise null. Do not invent clock times for meals, morning, or evening, or convert approximate times into exact ones.

This records timing, not causation. Do not carry a medication relation to another symptom without explicit support.
